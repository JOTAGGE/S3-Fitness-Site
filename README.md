# S3 Fitness — Site

Site institucional em React + TypeScript + Vite.

## Stack
- React
- TypeScript
- Vite
- React Router
- Lucide React
- CSS puro, responsivo

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Rotas
- `/`
- `/s3-fitness`
- `*` → 404

## Dados centralizados

Edite `src/data/site.ts` para alterar:
- nome e contato
- redes sociais
- endereço / Maps
- horários
- modalidades
- aulas
- depoimentos
- galeria

## Observação
As imagens usadas na base são imagens remotas do Unsplash como placeholders. Substitua pelas fotos oficiais da S3 antes da publicação comercial.

O conteúdo público de referência usado para a base aponta a S3 Fitness na Várzea, Recife, com endereço na Rua João Francisco Lisboa, 170, horário informado de segunda a sexta 05:30–22:00 e sábado 08:00–14:00, além de avaliações destacando atendimento, professores, organização, aparelhos e aulas coletivas.
